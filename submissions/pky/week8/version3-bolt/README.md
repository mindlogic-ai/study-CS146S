# Notes & Action Items Manager - Next.js + Prisma Version

*Generated via bolt.new, with minor manual adjustments.*

## Prerequisites
- Node.js 18+
- npm

## Setup & Run
```bash
npm install
npx prisma migrate dev --name init
npm run dev
```

Open http://localhost:3000 in your browser.

## Tech Stack
- **Framework:** Next.js 14 (App Router)
- **ORM:** Prisma
- **Database:** SQLite
- **Language:** TypeScript
