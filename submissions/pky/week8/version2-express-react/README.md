# Notes & Action Items Manager - Express + React Version

## Prerequisites
- Node.js 18+
- npm

## Setup & Run

### Backend
```bash
cd backend
npm install
npm start
```
Backend runs on http://localhost:5000

### Frontend
```bash
cd frontend
npm install
npm run dev
```
Frontend runs on http://localhost:5173 (proxies API to backend)

## Tech Stack
- **Backend:** Express.js + better-sqlite3
- **Frontend:** React 18 + Vite
- **Database:** SQLite
