## Prerequisites

- Supabase CLI (optional, for local development)

## Environment Variables

Create a `.env` file in the project root:

```bash
VITE_SUPABASE_URL=https://your-project.supabase.co
VITE_SUPABASE_ANON_KEY=your-anon-key
```

## Supabase Setup

1. Create a new project at https://supabase.com
2. Go to SQL Editor and run the migration in `supabase/migrations/20260324041428_create_notes_and_action_items.sql`
3. Deploy Edge Functions:
   ```bash
   supabase functions deploy notes
   supabase functions deploy action-items
   ```
4. Copy your project URL and anon key from Settings > API into `.env`
