# Expense Tracker — Next.js + Prisma

개인 가계부 웹 앱 (Next.js 버전)

## Prerequisites

- Node.js 18+

## Setup

```bash
npm install
npx prisma db push
npm run seed
```

## Run

```bash
npm run dev
```

Open http://localhost:3000

## Tech Stack

- Framework: Next.js 14 (App Router)
- ORM: Prisma
- Frontend: React + Recharts
- Database: SQLite
